# 🛒 Simple Grocery List

A minimal React desktop application to manage your daily grocery shopping.

---

## ✨ Features

- **Add items:** Type a product name and click _Add_ (or press `Enter`).
- **Complete items:** Toggle a checkbox to mark an item as bought.
- **Delete items:** Remove any item from the list.
- **Track progress:** View the total number of items and how many are completed.

---
