# 📌 Sidebar Navigation

A minimal, reusable React sidebar component with a title, multiple navigation tabs, and social links pinned to the bottom.

---

## ✨ Features

- **Title header:** Displays the app or project name at the top of the sidebar.
- **Navigation tabs:** Switch between multiple sections with a clean, active-state indicator.
- **Active tab highlighting:** The currently selected tab is visually distinguished.
- **Social links footer:** Quick access to social/network profiles (GitHub, LinkedIn, etc.) anchored at the bottom.
- **Responsive-ready:** Built with a component structure that's easy to adapt for collapsed/expanded states.
