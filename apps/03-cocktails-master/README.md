# 🍹 Cocktail App

A modern, interactive web application built with **React**, **TypeScript**, and **Vite** to discover, search, and explore delicious cocktail recipes.

---

## ✨ Features

- **Cocktail of the Day:** A featured cocktail highlighted directly on the homepage, changing daily to inspire your next drink.
- **Dynamic Search:** Quickly find cocktails by name or by specific ingredients.
- **Detailed Recipes:** Step-by-step preparation instructions with precise ingredients and measurements.
- **Responsive Design:** A clean, mobile-friendly interface designed for seamless use on any device.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Build Tool:** [Vite](https://vite.dev/)
- **Data Source:** [TheCocktailDB API](https://www.thecocktaildb.com/) _(or your preferred dataset)_
